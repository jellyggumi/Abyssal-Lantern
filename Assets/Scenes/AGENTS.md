# Scenes

## Purpose
Contains the Unity scene files for the project.

## Key Files

| File | Description |
|------|-------------|

## Subdirectories

## For AI Agents

### Working In This Directory
Be careful when modifying `.unity` files directly as they are serialized YAML files and highly prone to merge conflicts. It is recommended to use the Unity Editor to modify scenes.

### Testing Requirements
Open and play the scene in the Unity Editor to verify changes.

### Common Patterns
Standard Unity scene structure.

## Dependencies

- `Assets/TutorialInfo/` for readme/tutorial scripts
