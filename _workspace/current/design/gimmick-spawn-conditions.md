## 화산 분화구 (마그마 벤트) — `EruptionVentGimmick`

규칙 소유자는 `VentSchedule` (`Assets/Scripts/SiegeTactics.cs:148-183`).

| 항목 | 규칙 |
|---|---|
| **출현 턴** | `turn >= 2 && turn % 3 == 2` → 턴 **2, 5, 8, 11, 14…** (3턴 주기) |
| **위치** | x를 **−7.0 ~ +7.0** 중 **무작위** (`MinX`/`MaxX`) — 중립지 한정 |
| 높이 | y = **0.15** (`GroundY`, 지면) |
| **수명** | **3턴** (`LifetimeTurns`) 후 소멸 |
| 종류 결정 | `StyleForTurn(turn, stage)` — 아래 |
| 등장 연출 | `fx_spawn` 4프레임 + 알람 문구 (*"마그마 벤트 발생 (x=…) — 저공 사격 주의, 3턴 유지"*) |
| 예고 | 생성 직후 **경고 대역으로 즉시 진입**(`phaseOffset = dormantDuration - 1.2`) |

### 스테이지별 종류

| 스테이지 | 나오는 벤트 |
|---|---|
| **Stage1** | **마그마 ↔ 꽃가루 교대** — `(turn / 3) % 2 == 0`이면 마그마 |
| **Stage2** | **마그마 전용** (화산 스테이지) |
| **Stage3** | **서리 전용** |

> **정리: 화산(마그마) 분화구는 Stage2에서 턴 2·5·8·11…마다, 중립지 x −7~+7의 무작위
> 위치에 뜨고 3턴 뒤 사라진다.** Stage1에서도 턴 2, 8, 14…(`(turn/3)%2==0`)에 마그마가 뜨고
> 턴 5, 11…에는 꽃가루가 뜬다.

### 알려진 결함

**Stage3의 서리 벤트는 연출이 없다.** `EffectSpriteLibrary.Frost`(`fx_frost`)가 선언돼
있으나 디스크에 **0프레임**이라 `FrameAnimEffect.Spawn`이 `null`을 돌려주고 조용히 아무것도
그리지 않는다. 상세·제작 요청은 `design/impact-vfx-and-projectile-art-request.md` §0-2.

## 같은 자리에서 나오는 다른 조건들

### 벽돌 예약 (`BrickPlacementRules.DesignationOpen`)

원샷 턴 모드가 켜져 있으면 **열리지 않는다.** 조건 3개 전부 만족해야 한다:
`!EnforcesOneShotTurns && 적 턴 && !배치모드 무장`. 현재 기본값이 원샷이므로 **사실상 닫혀
있고**, HUD 문구도 이 술어를 읽어 함께 사라진다(작업 #52).

### 화포(대포) 해금 (`DeploymentRules`)

턴 조건 + **적 성벽 2블록 돌파** + 보급 12. 자기 벽을 부수는 우회는 "누구 벽이 무너졌나"로
집계해 구조적으로 차단된다(작업 #27).
