# 획 충실도 실측 — 면적이 아니라 형태로

같은 문자열을 같은 출력 크기로 두 번 그린다: (A) 크기 S로 직접,
(B) 크기 8S로 그린 뒤 박스 필터로 S까지 축소. B는 모든 획이 해상된 기준이다.
A가 획을 잃은 자리에서만 둘이 어긋나므로, 불일치율이 곧 획 손실이다.
