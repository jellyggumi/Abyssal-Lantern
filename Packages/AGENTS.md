# Packages

## Purpose
Defines the project's package dependencies and lock states for the Unity Package Manager.

## Key Files

| File | Description |
|------|-------------|
| `manifest.json` | Lists the packages and their versions required by the project |
| `packages-lock.json` | Lock file containing the exact resolved versions and hashes of all packages and their dependencies |

## For AI Agents

### Working In This Directory
Modify `manifest.json` to add or remove packages. Do not manually edit `packages-lock.json` as it is auto-generated by Unity.

### Testing Requirements
Open the project in Unity to verify that packages resolve and compile successfully.
