## `spec-kit` 스킬 요약

**무엇:** GitHub의 [`spec-kit`](https://github.com/github/spec-kit) — Spec-Driven Development(SDD) 워크플로우 도구 `specify` CLI를 감싸는 라우팅 우선 래퍼.

**사전 준비:** Python 3.11+, `uv` (또는 `pipx`), `git`, 지원 AI 에이전트 1개.

**설치:**
```bash
uv tool install specify-cli --from git+https://github.com/github/spec-kit.git
# 재현성: @v0.0.10 같은 태그/SHA로 pin
specify --version
specify integration list
```

**프로젝트 부트스트랩:**
```bash
specify init my-project --integration claude   # 또는 copilot, gemini, codex, cursor, opencode, qwen, kiro, ...
specify init . --integration copilot           # 현재 디렉터리
specify init --here --force --integration gemini
```
→ `.specify/`, 에이전트별 커맨드 파일, constitution 템플릿 생성.

**SDD 슬래시 명령 (선택한 에이전트 안에서 실행):**

| 명령 | 역할 |
|------|------|
| `/speckit.constitution` | 프로젝트 원칙·결정 규칙 |
| `/speckit.specify` | 요구사항·유저스토리·성공 기준 |
| `/speckit.clarify` | 스펙 모호성 인터뷰 (선택) |
| `/speckit.plan` | 기술 구현 전략 |
| `/speckit.analyze` | constitution↔spec↔plan 정합성 점검 (선택) |
| `/speckit.tasks` | 실행 가능한 태스크 분해 |
| `/speckit.checklist` | 게이트용 리뷰 체크리스트 (선택) |
| `/speckit.implement` | 태스크 단위로 코드 실행 |

**커뮤니티:**
```bash
specify extension search / add <name>
specify preset search / add <name>
```

**플러그인 설치 (oh-my-skills 흐름):**
```bash
npx skills add https://github.com/akillness/oh-my-skills --skill spec-kit
npx skills add -g https://github.com/akillness/oh-my-skills --skill spec-kit -a claude-code -a codex -y
```
또는 동봉 스크립트: `bash .agent-skills/spec-kit/scripts/install.sh` (env: `SPEC_KIT_REF`, `SPEC_KIT_INTEGRATION`, `SPEC_KIT_PROJECT_DIR`).

**언제 쓰지 말 것 (route-out):**
- 벤더 중립 spec-first 루프 → `ooo`
- 패킷 우선 BMAD/BMM 다음 산출물 선택 → `bmad`
- 기존 plan/diff 시각 승인 → `plannotator`
- 사전 기획 컨셉 다듬기 → `bmad-idea`

**모범 운영:** ref pin → 한 repo에 통합 하나 → constitution을 가장 먼저 갱신 → `clarify`로 모호성 해소 후 `plan` → level 2+ 작업은 `implement` 전에 `plannotator` 검토.
