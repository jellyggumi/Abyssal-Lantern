## 8. Structural import: install pipeline (ralph pass 2)

GJC ships a single `scripts/install.sh` (264 lines) that handles both
source-via-bun and prebuilt binary modes with a strict `MIN_BUN_VERSION=1.3.14`
gate. The runtime entry (`packages/coding-agent/src/cli.ts`) also re-checks
`Bun.semver.order(Bun.version, MIN_BUN_VERSION) < 0` before doing anything else,
and sets `process.title = APP_NAME` so `ps`/`pgrep` show the agent under its own
name.

joc now mirrors that structural pattern:

| Concern | GJC | joc (added this pass) |
|---|---|---|
| One-shot installer | `scripts/install.sh` (curl-pipe-sh) | `coding-agent/scripts/install.sh` |
| Modes | `--source` / `--binary` / `--ref` | `--local` (dev clone) / `--source` (clone repo) / `--ref` |
| Bun version floor | `MIN_BUN_VERSION=1.3.14` shared via `@gajae-code/utils` | constant in `install.sh` + runtime guard in `src/cli.ts` |
| Install target dir | `$GJC_INSTALL_DIR` ‖ `$HOME/.local/bin` | `$JOC_INSTALL_DIR` ‖ `$HOME/.local/bin` |
| PATH hint | yes — warns if INSTALL_DIR not on PATH | yes — same message structure |
| Uninstall | `bun remove -g …` documented | dedicated `scripts/uninstall.sh` with `--purge` for `~/.joc/` |
| Process identity | `process.title = APP_NAME` | added to `src/cli.ts` |

Both the installer and the post-install CLI were run with `env -i` to guarantee
no environment leaked from the parent shell. The Bun version guard inside
`src/cli.ts` is the runtime floor; the installer enforces the same minimum
before symlinking so a misconfigured machine fails at install-time, not at
first command.

### What we did *not* mirror (intentional)

- `Dockerfile`, `Dockerfile.robogjc`, multi-arch native binary release pipeline.
  joc is single-package, source-only for now. Prebuilt binaries are a future
  release-pipeline concern, not a structural gap.
- `crates/` (Rust workspace) and `python/` siblings — joc has no Rust/Python
  helpers to bring across.
- The 50+ `src/<subdomain>/` modules under gjc's coding-agent (autoresearch,
  capability, dap, lsp, mcp, plan-mode, etc.). Those are *features*, not
  structural scaffolding. We keep joc's tighter surface: `agent/`, `commands/`.
