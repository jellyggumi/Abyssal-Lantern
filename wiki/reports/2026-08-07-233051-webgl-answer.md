# 원인이 확정됐습니다 — **열려 있는 에디터에서는 WebGL 빌드가 구조적으로 불가**합니다:

## Answer Output (rtk-compressed)

원인이 확정됐습니다 — **열려 있는 에디터에서는 WebGL 빌드가 구조적으로 불가**합니다:

- 실패 원인: unity-mcp 패키지의 Runtime 코드가 WebGL 플레이어 컴파일에서 깨짐 (`CS0246/CS0115`)
- `BuildScript.ExcludeEditorToolingFromWebGl()`이 빌드 직전 `UNITY_MCP_READY` define을 제거하지만, **살아 있는 에디터에서는 MCP 리졸버가 도메인 리로드마다 define을 재설치**합니다 — 방금 확인 결과 define이 다시 들어와 있습니다
- 즉 "빌드를 걸어주는 MCP 브리지"가 "빌드를 깨는 원인"이라 같은 에디터 안에서는 해결 불가. 이전 성공 빌드(오늘 00:17)는 배치모드 산물로 보입니다 (배치 스크립트는 `UNITY_MCP_KEEP_CONNECTED=false`로 리졸버를 잠재움)

**여기까지 완료된 것**: 레인 구현 전체, EditMode 666/666, 커밋 5개. 남은 것은 WebGL 빌드 1건뿐입니다.

빌드를 마치려면 **Unity 에디터를 닫아야** 합니다 (프로젝트 락 해제 → 배치모드 실행). 에디터가 다른 세션/직접 사용 중일 수 있어 제가 임의로 종료하지 않았습니다. 두 가지 중 선택해 주세요:

1. **에디터를 직접 닫아주시면** 제가 `bash tools/unity_batch.sh method CinderCourt.EditorTools.BuildScript.BuildWebGL`로 배치모드 빌드 + 용량 게이트(≤120MB) 검증까지 완료하겠습니다
2. 아니면 **제가 MCP로 에디터를 종료**하고 진행할까요? (열린 씬에 저장 안 된 변경이 있으면 유실 위험이 있어 확인 후 진행합니다)
